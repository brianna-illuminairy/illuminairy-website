Before picking a library

Steal from charts parents already trust

Not a catalog of chart types. Real editorial products and what to borrow for SAT diagnostic, plan reveal, and parent updates.

Use this board to say “more like this, less like edtech dashboard.” Then open 12-sat-viz-specimens.html for full-width mocks with real Soha data + ECharts.

Datawrapper

datawrapper.de · gallery: examples

Publication default for newsrooms. Clean type, responsive embeds, accessible tables and maps. Boring in a good way.

  • Steal: headline as chart title (“Transitions cost her the most points”)
  • Steal: direct labels on the mark, no legend box
  • Steal: source + “Results vary” strip in mono under every graphic
Illuminairy SATAccuracy by E/M/H · section dumbbell (diag → PT) · simple locator if geo ever matters

Flourish

flourish.studio · template gallery

Story-first interactives: sankey, slope, bar chart race, scrollytelling. More motion than Datawrapper.

  • Steal: sankey for misses → skill tags → modeled points (one graphic tells the “why rank” story)
  • Steal: slopegraph when comparing two test dates across 5 skills
  • Skip: bar chart race (tutor-ad energy)
Illuminairy SATSankey on diagnostic report · plan reveal slope (start vs goal skill accuracy)

The Economist

Graphic Detail · FT Chart Doctor / Visual Vocabulary

One message per chart. Minimal grid. One accent color. Serif numbers where it matters.

  • Steal: dumbbell for current ↔ goal (not twin bars)
  • Steal: step line when weekly gain phases change (25 → 15 → 5 pts/wk)
  • Steal: small multiples (RW panel + Math panel, same scale)
Illuminairy SATPlan reveal trajectory · achievability as tier labels, not a gauge

NYT Graphics / The Upshot

The Upshot · custom D3 (no npm chart defaults)

Gold standard for bespoke layout. They build custom — but the patterns are copyable: unit charts, small multiples, annotation.

  • Steal: unit dot matrix for “13 of 98 missed” without a red grid
  • Steal: prose + one chart per scroll section (not six widgets)
  • Don’t copy: their engineering stack — copy the hierarchy
Illuminairy SATConstellation / icon array for question map · narrative diagnostic scroll

RAWGraphs

rawgraphs.io

Fast sandbox for unusual encodings: alluvial, bump, treemap, circle packing. Export SVG for moodboards.

  • Use for: 30-minute “what if treemap for ranked skills?” experiments
  • Not for: production embed in Next.js
Illuminairy SATIdeation only · paste SVG into Figma or specimen HTML

Apache ECharts (production engine)

echarts.apache.org/examples

What we use in 12-sat-viz-specimens.html — real library, not wireframe thumbnails. Sankey, treemap, step line, theme registration.

  • Steal from examples: sankey-energy, treemap-disk, line-step, custom dumbbell via scatter + line
  • Theme: register once with aurora palette; never use default rainbow
Illuminairy SATShip in Next.js via echarts-for-react after you pick a specimen layout
