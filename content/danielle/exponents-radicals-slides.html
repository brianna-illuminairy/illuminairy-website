Exponents and radicals

We will start with what the pieces mean, learn each rule with worked examples, practice it, then apply it to a real SAT problem. By the end, the goal is that you recognize which form a question wants and rewrite to match it.

Start here

What is a base? What is an exponent?

23
The base is 2, the number being multiplied.
The exponent (also called the power) is 3, how many times you multiply the base by itself.

So an exponent is just shorthand for repeated multiplication:

23 = 2 × 2 × 2 = 8
52 = 5 × 5 = 25
104 = 10 × 10 × 10 × 10 = 10,000
Two you should just know: anything to the first power is itself (a1 = a), and anything to the zero power is 1 (a0 = 1).

Divide, same base

Power of a power
(am)n = amn
(22)3 = 26 = 64
Power of a product
(ab)n = anbn
(2 · 3)2 = 22 · 32 = 36
Power of a quotient
(ab)n = anbn
(23)2 = 49
Negative and zero
a−n = 1an,   a0 = 1
2−2 = 14,   70 = 1

What is a radical?

A radical asks the reverse of a power: what number, raised to a given root, gives what is inside?

3√8
The index is 3, which root you are taking (a cube root here). With no number written, the index is 2, a square root.
The radicand is 8, the number under the radical symbol.
√9 = 3 because 32 = 9
3√8 = 2 because 23 = 8
√25 = 5 because 52 = 25
A radical is a power in disguise: a square root is the same as the 1/2 power, which is the bridge we use later.

A skill you will use constantly

Rewriting a number as a power of a smaller base

Many numbers are secretly a small base raised to a power. Recognizing this is what lets you compare or combine expressions. Learn these two families cold.

Powers of 2
2 = 21, 4 = 22, 8 = 23, 16 = 24, 32 = 25, 64 = 26
Powers of 3
3 = 31, 9 = 32, 27 = 33, 81 = 34
Why it matters: if a problem mixes 4, 8, and 16, you can rewrite them all as powers of 2 and suddenly the bases match, which is the only way the exponent laws apply.

Calculator shortcut

Finding a missing exponent in Desmos

Sometimes you know the base and the result, and need the exponent. For example, 3? = 81. Two fast ways in Desmos:

1Type the equation with x as the unknown exponent:
3^x = 81
Desmos graphs it and marks the solution x = 4, since 34 = 81.
2Or use a logarithm, which asks that exact question directly:
log_3(81)
Desmos returns 4.
When to reach for this: you know the base and the output and need the power. On the no-calculator section you would instead rewrite 81 as 34 by hand, which is why the power families on the last slide are worth memorizing.

Law 1 · multiply with the same base

am · an = am+n
Same base, multiply: keep the base, add the exponents.
23 · 24 = 23+4 = 27 = 128
x2 · x5 = x7
Read it both ways: a sum in one exponent can be split back apart, so 27 = 23 · 24. That split is exactly the trick for the SAT problem next.

aman = am−n
Same base, divide: keep the base, subtract the exponents.
2723 = 27−3 = 24 = 16
x9x2 = x7
Read it both ways: a difference in an exponent can become a division, so 5p−q = 5p5q. That is the SAT move on the next slide.

Law 3 · a power raised to a power

(am)n = amn
Keep the base, multiply the exponents.
(23)2 = 26 = 64
(x4)3 = x12
Read it both ways: you can pull a base apart too. Since 16 = 42, 16x = (42)x = (4x)2. That rewrite is what the SAT problem needs.

Law 4 · negative and zero exponents

a−n = 1an,   a0 = 1
A negative exponent means reciprocal, not a negative number.
2−3 = 123 = 18
x−2 = 1x2
50 = 1, 1000 = 1
Read it both ways: a fraction can become a negative exponent, so 19 = 3−2.

Law 5 · fractional exponents are radicals

am/n = (n√a)m
The bottom of the fraction is the root, the top is the power.
91/2 = √9 = 3
81/3 = 3√8 = 2
272/3 = (3√27)2 = 32 = 9
Read it both ways: a root is a fractional power, so √x = x1/2 and 3√x2 = x2/3. Switching to exponents often makes the algebra easier.

On the SAT · when neither side is ready

Sometimes the two sides use different bases, and neither is the one you want. Rewrite both down to a common small base first.

4x = 8 = 22x = 23 so 2x = 3, x = 3⁄2
9x = 27 = 32x = 33 so x = 3⁄2
Distribute carefully: when the exponent is an expression like x − 1, the rewrite multiplies the whole thing. 8x−1 = 23(x−1) = 23x−3, not 23x−1.

On the SAT · the sneaky ones

Combine before you match

Do not write 2x + 2x = 4x. Adding two copies of the same power doubles it, it does not change the base: 2x + 2x = 2 · 2x = 2x+1.
2x + 2x = 2 · 2x = 2x+1 two copies double
2x + 2x+1 = 2x(1 + 2) = 3 · 2x factor out the smaller power
Exercise

Hint
Step-by-step solution

264 = 26, so 2x+1 = 26, giving x + 1 = 6, x = 5. Choice A.
3Choice B treats the left as a single 2x = 64. Choice C treats it as 22x = 64. Choice D reports 2x = 32 instead of x.

Putting it together · how to start

A harder one: where do you even begin?

Suppose you see 8x2y and a fact like 3x − y = 10. Work through three questions before touching it.

1Same base or same power? The exponents x and y are different unknowns, so you cannot match powers. But the bases 8 and 2 are both powers of 2, so match the base. Write 8 = 23, giving 8x = 23x.
2Now it is 23x2y. Do the 2's cancel? No. They are not separate factors you can strike out. Dividing powers of the same base means subtract the exponents: 23x−y. The base 2 stays.
3What do you know? The exponent is now 3x − y, which you were told equals 10. So the whole thing is 210.
The habit: when bases differ, ask whether they share a smaller base before anything else. Matching the base is what lets every other rule apply.

Law 6 · simplifying radicals

√ab = √a √b
Pull out the largest perfect square factor and take its root out front.
√72 = √36 · 2 = 6√2
√50 = √25 · 2 = 5√2
√18 = √9 · 2 = 3√2
Perfect squares to know: 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144. Always factor out the biggest one so nothing is left to simplify.

Law 7 · rationalizing the denominator

Multiply top and bottom by the same square root
A single square root in the denominator clears when you multiply it by itself.
1√2 = 1√2 · √2√2 = √22
6√3 = 6√33 = 2√3
Why bother: the SAT usually writes answer choices with no radical in the denominator, so you match their form by rationalizing.

Law 8 · conjugates with radicals

(a − b)(a + b) = a2 − b2
When the denominator has two terms with a radical, multiply by its conjugate to clear it.
The conjugate of 3 − √5 is 3 + √5
(2 + √3)(2 − √3) = 22 − (√3)2 = 4 − 3 = 1
The point: multiplying by the conjugate squares away the radical, since the middle terms cancel and you are left with a2 − b2.

Law 9 · radical equations

Square both sides, then check every solution
Squaring can create fake answers, so always test them in the original equation.
√x = 6 square both sides x = 36 check: √36 = 6
√2x + 3 = 5 square 2x + 3 = 25 so x = 11
The habit: isolate the radical, square, solve, then plug each answer back in. Any that fail are extraneous and get thrown out.
Exercise

Hint
Step-by-step solution
1Square both sides: 2x + 3 = 25.
2Solve: 2x = 22, so x = 11.
3Check: √2(11) + 3 = √25 = 5. Works. Choice A.

On the SAT · extraneous solutions

Watch for the fake answer

Select an answer, then check it or open the steps.
Hint
Step-by-step solution
1Square both sides: (m + 4)2 = m + 10, so m2 + 8m + 16 = m + 10.
2Set to zero: m2 + 7m + 6 = 0, so (m + 1)(m + 6) = 0. Candidates −1 and −6.

On the SAT · where a line meets a parabola

Both equations equal y, so set the right sides equal, move everything to one side, and solve the quadratic. The solutions are the intersection points.

Solving a nonlinear system

Select an answer, then check it or open the steps.
Hint
Step-by-step solution
1Both equal y: x2 − 3 = 2x.
2Set to zero: x2 − 2x − 3 = 0, so (x − 3)(x + 1) = 0.
3x = 3 or −1. Choice A. The points are (3, 6) and (−1, −2).

On the SAT · exactly one solution

A line and a parabola meet once when they are tangent. After setting them equal, that means the quadratic has one repeated root, so the discriminant b2 − 4ac equals 0.

Using the discriminant
For what value of k does the system y = x2 and y = 6x − k have exactly one real solution?
Select an answer, then check it or open the steps.
Hint
Step-by-step solution
1Set equal: x2 = 6x − k, so x2 − 6x + k = 0.
2One solution means discriminant 0: (−6)2 − 4(1)(k) = 0.
336 − 4k = 0, so k = 9. Choice A.

The one idea

Recognize the useful form, then rewrite to match it

Start by asking whether the bases can be made to match, or whether a radical is really a fractional power. Once the forms line up, the exponent and radical laws do the rest, and the arithmetic is short. Always test radical-equation answers before you commit.
