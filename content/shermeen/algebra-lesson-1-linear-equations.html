Slope and Intercepts

An Equation with Two Variables Has a Whole Line of Answers

A two-variable equation has infinitely many answers, and those answers form a straight line. This is why working with two variables means working with lines.

With one variable, an equation like x + 5 = 8 has one answer: x = 3. With two variables, an equation like x + y = 5 is asking for two numbers that add to 5. There are infinitely many such pairs: (0, 5), (2, 3), (5, 0), and every point in between. Plot them all and they lie on a straight line.

Every point on the line is a pair (x, y) that makes x + y = 5 true. Every point off the line does not. That is why a two-variable equation is drawn as a line: the line is a picture of every answer at once.

The Same Math, Written as a Function

Every skill you have learned about y = mx + b still applies. Function notation just gives us a cleaner way to talk about the rule and its inputs and outputs.

Everything up to this point has been about linear equations: solving them, reading their slope and intercepts, building them from data. From here on, the same equations show up in a new form: function notation. The math is identical. Only the way it is written and named changes.

y = mx + b   →   f(x) = mx + b

The next module explains what f(x) means and how to work with it.

What a Function Is

A function is a rule you feed a number into and get a number back out of.

A function is a rule that takes an input, does something specific to it, and gives back an output. Every time you give it the same input, you get the same output back. The rule can be anything: multiply by 3 and add 5, subtract 7, square the number, and so on.

The rule for this function: multiply by 3, then add 5.

Give it 2, it hands back 11. Give it 4, it hands back 17. Give it −1, it hands back 2.

The Letter Is the Function's Name. The (x) Tells You What the Input Is Called.

The letter is only a name. Different letters (f, g, h) label different functions, so we can talk about more than one at a time.

f (x) = 3x + 5

f is the name of the function, like a person's name. Nothing special about the letter f. You could call this function g, or h, or k. They are just names.

(x) says the input variable is called x. Wherever an x shows up on the right side, that is a placeholder for whatever number you put in.

If a problem has two functions in it, they usually get different names, like f(x) = 2x + 1 and g(x) = 5x − 3. Same idea, different function.

f(3) Means "Evaluate f at 3." It Does Not Mean f Times 3.

f(3) is a request to evaluate the function at input 3. Substitute 3 for x, then simplify.

the trap

f × 3

f(3) is not multiplication. Reading it that way changes the whole problem.

the right read

f(3) = 3(3) + 5 = 14

"Put 3 in wherever x appears, then compute."

When you see f(3), read it as "f of 3" and treat the number in parentheses as the input.

How Shifts Change a Linear Function

Adding to the output shifts up. Subtracting from the input shifts right. The direction of the input shift is opposite to the sign.

start withf(x) = 2x + 3
f(x) + 4shift the whole graph up by 4: 2x + 7
f(x) − 4shift the whole graph down by 4: 2x − 1
f(x + 2)shift left by 2: 2(x + 2) + 3 = 2x + 7
f(x − 2)shift right by 2: 2(x − 2) + 3 = 2x − 1

The Slope Stays the Same, the Intercept Moves

Shifts never change the slope. They only move the line up, down, left, or right.

Both lines have slope 2. Shifting up or down changes the intercept but leaves the slope alone, so the lines stay parallel. Shifting left or right also leaves the slope alone.

The next four modules teach how to solve systems, count solutions, find missing constants, and match a system to its graph.

Up to this point, every equation has stood alone. From here, we work with two equations together. A pair like this is called a system of linear equations, and the goal is to find the (x, y) that makes both equations true at the same time.

y = x + 1

y = −x + 5

The solution to this system is (2, 3). It works in both equations.

A System Is Two Equations, One Answer Pair

The solution to a system is the pair of numbers that makes every equation true at once. Graphically, it is the point where the lines meet.

A system of linear equations is two (or more) equations that share the same variables. The solution is a pair (x, y) that satisfies both equations at the same time. On a graph, that is the point where the two lines cross.

y = x + 1 and y = −x + 5 cross at (2, 3).

Check: 3 = 2 + 1 and 3 = −2 + 5. The point makes both equations true, so it is the solution to the system.

Substitution: Replace One Variable Using the Other Equation

Substitution turns a two-variable problem into a one-variable problem. Best when one equation already has a variable isolated.

If one equation is already solved for a single variable (like y = 3x + 2), take that expression and put it into the other equation. You get one equation in one variable, which you already know how to solve. Then plug the answer back to find the other variable.

1
Solve one equation for one variable.
2
Substitute that expression into the other equation.
3
Solve for the remaining variable, then find the first one.

Worked example

Solve by substitution: y = 3x + 2 and 2y = 9x − 5

Substitute the expression for y, then solve one move at a time.

put 3x + 2 in for y in the second equation: 2(3x + 2) = 9x − 5
distribute on the left: 6x + 4 = 9x − 5
subtract 6x from both sides: 4 = 3x − 5
add 5 to both sides: 9 = 3x
divide both sides by 3: x = 3
put x = 3 back into y = 3x + 2: y = 11

Elimination cancels one variable so you can solve for the other. Best when both equations are in the form ax + by = c.

2

3

Solving Linear Inequalities

An Inequality Is Like an Equation, With a Direction

The answer to an inequality is usually a range of values, not a single number.

An inequality uses <, >, ≤, or ≥ instead of an equal sign. Instead of asking "what value makes both sides equal?" it asks "which values make the left side less than (or greater than, or equal to) the right side?"

<less than
>greater than
≤less than or equal to
≥greater than or equal to

Solve an Inequality the Same Way You Solve an Equation, Except for One Rule

Every move works the same as in an equation, except one. If you multiply or divide by a negative, the sign flips.

the one rule that is different

When you multiply or divide both sides by a negative number, flip the direction of the inequality.

Example: −2x < 8. Divide both sides by −2. The sign flips: x > −4.

Adding or subtracting the same number on both sides is fine. Multiplying or dividing by a positive number is fine. Only a negative multiplier or divisor forces the flip.

Worked example

Solve 3x − 5 > 7

No negative multipliers or divisors here, so the sign never flips.

3x − 5 > 7
add 5 to both sides.
3x > 12
divide both sides by 3 (positive, so no flip).
x > 4
the solution is every value of x that is greater than 4

Worked example

Solve 6 − 2x ≥ 14

Divide by a negative, flip the sign. This is the one rule that separates inequalities from equations.

6 − 2x ≥ 14
subtract 6 from both sides.
−2x ≥ 8
divide both sides by −2. Flip the sign.
x ≤ −4
the solution is every value of x that is less than or equal to −4

Compound Inequalities: Two Bounds at Once

Treat the three parts as one shape. Every step happens on the left, the middle, and the right.

A compound inequality is two inequalities stuck together on either side of a middle expression. Every value that makes it true has to satisfy both sides at the same time.

2 < x + 5 < 9

Read it as two things at once: "x + 5 is greater than 2" AND "x + 5 is less than 9."

To solve: do the same move to all three parts at the same time. Whatever you subtract from the middle, subtract from both ends.

Worked example

Solve 2 < x + 5 < 9

The answer to a compound inequality is a range, written the same way as the original.

2 < x + 5 < 9
subtract 5 from all three parts.
2 − 5 < x + 5 − 5 < 9 − 5
simplify each part.
−3 < x < 4
the solution is every x between −3 and 4 (not including the endpoints)

Rewrite the absolute value inequality without the bars first. Then solve as a compound inequality or as two cases.

|x| means the distance of x from 0 on the number line. So |x| < 5 asks "which numbers are within 5 of 0?" and |x| > 5 asks "which numbers are more than 5 away from 0?"

|A| < B (or ≤)rewrite as a compound inequality: −B < A < B

Less-than absolute value inequalities become a single range. Greater-than ones become two separate ranges.

When a Question Asks for a Largest or Smallest Value, Solve the Inequality All the Way

The boundary value (the number on the other side of the sign) is the max or the min. The direction of the sign tells you which.

The word "maximum" (or "at most") means: what is the largest value the variable can take and still make the inequality true? The word "minimum" (or "at least") means: what is the smallest value that still works?

For an inequality like x ≤ 8, the maximum value of x is 8. Any larger number would make it false.

For x ≥ 5, the minimum value of x is 5.

Why x ≤ 8 Means the Maximum Is 8 (and x < 8 Does Not)

The sign tells you whether the boundary value counts. If it counts, it is the answer.

The ≤ sign includes the boundary value. That single fact is what turns "x is at most 8" into a real maximum you can name.

x ≤ 8: maximum is 8

the closed dot at 8 means x can equal 8. So 8 itself is a valid value, and no value larger works.

x < 8: no clean maximum

the open dot at 8 means x can get as close to 8 as you like but never actually reach it. For integer counts, the largest x that works is 7.

Phrases like "at most 8" and "no more than 8" always mean x ≤ 8, so 8 is the max. Phrases like "less than 8" or "under 8" mean x < 8, so 8 is not.

Worked example

Set up the inequality from the words, plug in the given value, then read off the boundary.

translate "z is at most 24 more than twice t"
"at most" means ≤
"24 more than twice t" means 2t + 24
so z ≤ 2t + 24
substitute t = 10.
z ≤ 2(10) + 24
simplify the right side.
z ≤ 44
the maximum value of z is 44
