# Illuminairy plan

## When to use

- New feature, page, API, or integration
- User asks to "plan" or scope work
- Before multi-session Ralph implementation

## Steps

1. Read `AGENTS.md`, `memory-bank/activeContext.md`, `memory-bank/productContext.md`.
2. Read `specs/ACTIVE.md`; if `(none)`, offer to create `specs/YYYY-MM-slug/` from `specs/_templates/`.
3. For product questions, use YC-style clarity: problem, user, success metric, non-goals.
4. Output: PRD bullets, SPEC acceptance criteria, suggested `specs/ralph/PLAN.md` tasks (one task per Ralph session).
5. Do not change `lib/site.ts` facts unless the user explicitly approves.
