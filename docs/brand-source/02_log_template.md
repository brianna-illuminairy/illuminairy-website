# Customer Discovery Call Log Template

> Format: **one row per call**. Pick a tool and stick with it (Notion table, Airtable, or Google Sheet — all fine).
> Time to fill: **15 minutes within 30 minutes of the call.**

---

## Columns

| Column | What goes here |
|---|---|
| **Date** | YYYY-MM-DD |
| **Name** | First + last |
| **Role / Title** | Job title at time of call |
| **Company / Vertical** | dental / marketing / legal / SaaS / consulting / e-comm / other |
| **Source** | A / B / C / D / E / F (from call list) |
| **Q1 — what they tried** | 2–3 sentence summary of their last AI-application attempt |
| **Q2 — what it cost** | Money $, time, opportunity cost (real numbers, not "a lot") |
| **Q3 — where it broke** | The specific failure point in their words |
| **Q4 — 12-mo spend** | List: courses bought, coaches paid, tools subscribed, hires made. Mark each Used / Abandoned. |
| **Q5 — who helped** | Name + what they did + what they didn't |
| **Q6 — snowball** | Names + intros offered (or "none offered" — that's a signal too) |
| **🪙 Gold quote** | The 1 verbatim sentence too good to lose. Use later for landing-page copy. |
| **Signal** | FOR / AGAINST / NEUTRAL (does this support the IlluminAIry hypothesis?) |
| **ICP tags** | dentist? marketing-director? founder? IC vs. owner? solo vs. team? |
| **Followup** | "yes-show me" / "no" / "maybe-circle back in 30 days" |

---

## Daily / weekly review

**Daily** — after each call, fill the row. Don't batch.

**Weekly (every 5 calls)** — re-read the gold-quote column out loud. Two questions:
1. **Pattern check** — what phrase/pain is showing up in 3+ rows? That goes into the Module 11 customer language file.
2. **Beachhead check** — which vertical / ICP cluster has the highest density of FOR signals + budget + snowball density? That feeds Module 4 (Beachhead Choice).

---

## What "done" looks like

After 15 calls you should be able to fill these in:

- **Top 3 verbatim phrases** that show up across 5+ interviews
- **The vertical / persona** with the highest hair-on-fire density
- **The specific failed alternative** customers spent the most on (= our anti-position)
- **3+ people who said "show me when you have something"** (= first 3 design partners)
- **A name for the wedge** (= Module 10 input)
